# Retreat-Website

The web platform of the Retreat ecosystem, where users discover and play games in the browser.

- Game catalog with pages for each game: description, screenshots, videos, and rankings, with a clear path to play.
- Unified player account and wallet shared across games.
- Shared marketplace where players trade items from games, powered by the ecosystem's digital currency (fixed total supply).
- Each game keeps its own rules and item economy; the platform provides identity, currency, and marketplace infrastructure, and validates global transactions.

## Part of the Retreat ecosystem

- [Retreat-CoreSDK](https://github.com/RetreatSoftware/Retreat-CoreSDK) — shared SDK
- [Retreat-Forge](https://github.com/RetreatSoftware/Retreat-Forge) — game creation tool
- [Retreat-Modules](https://github.com/RetreatSoftware/Retreat-Modules) — pluggable gameplay systems
- [Retreat-Engine-3D](https://github.com/RetreatSoftware/Retreat-Engine-3D) — 3D game engine
